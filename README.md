# Bug Hunt

A quick QA game. Read the test log and click every row where the actual result does not match the expected one before the timer ends.

**Live demo:** https://ajjuahmad.github.io/bug-hunt/

## How it works

Three rounds with more defects and less time each round. Each correct click scores 10 points, a false alarm costs 5, and finishing early adds a time bonus. Test cases are generated fresh each round, and your best score is kept in the browser.

## Run it locally

It is a single `index.html` file with no build step. Download it and open it in a browser.
